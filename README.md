# SecurePass — Password Strength Analyzer

SecurePass is a Python desktop application that analyzes password security and helps users create stronger credentials through intelligent suggestions.

## Features

- Password strength evaluation
- Secure password generation
- Password visibility toggle
- Best-practice guidance
- User-friendly desktop interface
- Expandable architecture

## Built With

- Python
- Tkinter
- Random
- String
- Regex

## How It Works

SecurePass analyzes password quality based on:

- Length
- Uppercase characters
- Lowercase characters
- Numbers
- Symbols
- Common pattern detection

The application then provides feedback and can generate stronger alternatives.

## Installation

Clone repository:

```bash
git clone  https://github.com/albratoss0/SecurePass.git
```

Run:

```bash
python app/main.py
```
